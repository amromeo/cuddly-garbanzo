# OLSD UI prototype

Static, sample-data prototype for independent workflow and usability review.

Open `index.html` for the app, `review.html` for the reviewer guide and screenshots, or `source.txt` for the complete client source. No dependencies or build step.

GitHub Pages deployment: publish the `main` branch, root folder. The application does not connect to production services. Uploaded handoff files, SQL, source workbooks, archived pins, browser storage, and credentials are not included. Demo Excel downloads must not be imported into OLSD.
